# Decisions

A written decision lives here when the clean-room rule needs one, or when a
question the public sources leave open has to be settled once and for all. One
file per decision, named for what it settles.

Each states what was decided, the date, the reason, and what it allows. The
places that rely on it link to it, so `docs/CLEAN-ROOM.md` can point here
instead of arguing the case again.

- [Hard-linked files are not tagged](hard-linked-files.md)
- [A tag save writes a new file and puts it in place](tag-saves-replace-the-file.md)
- [Deleting a file sends it to the trash, after a question](deleting-goes-to-the-trash.md)
- [A deleted track's row is kept for thirty days](a-deleted-track-is-kept-thirty-days.md)
- [ReplayGain is applied on playback; Smart Gain is not copied](replaygain-on-playback.md)
- [Undo for tags is one step](tag-undo-is-one-step.md)
- [An ID3v2.3 save does not move what it cannot keep](id3v23-values-not-moved.md)
- [Rules where the public pages do not say what MusicBee does](where-the-wiki-is-silent.md)
- [Differences from MusicBee that are kept](kept-differences-from-musicbee.md)
- [Where MusicBee's documented behaviour is followed](follow-the-documented-behaviour.md)

Each file gives its status. "Decided by the owner" is a decision of the
project's owner, with its date; a file never names a person.
