# Review of the specs' sources, 2026-11-20

**What was reviewed:** every spec in `docs/spec/` and `docs/MANUAL.md`,
against the public MusicBee wiki and `CLEAN-ROOM.md`. An outside list
of findings was checked page by page; where it was wrong it was not
followed.

**What changed in the specs** (no rule of the program changed):

1. **Sources.** Links that led to no page now lead to the one that holds
   the matter; every wiki source has its link; tags were added where a
   statement had none; each Sources section ends with each page's
   version and date of last edit. Specs with no Sources section have one.
2. **Questions.** 28 open questions were answered from the wiki, whole or
   in part, and some were added. Where the wiki disagrees with itself,
   both sides are written.
3. **Hygiene.** No spec says any more that it rests on what someone
   remembered of MusicBee: those rules are the owner's rulings, said to
   be so. Contradictions inside a spec were mended. What is linuxBee's
   own, and the differences that are kept, are said to be so.
4. **Records.** The owner's rulings have files in `docs/decisions/`;
   `docs/sources.md` lists every source; `docs/questions.md` says how a
   question is closed; this file records the review.

**What follows:** the behaviour the owner chose to follow
(`docs/decisions/follow-the-documented-behaviour.md`) is built in
packages, each with its tests, and each spec changes with its package.
